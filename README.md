# ProductChallenge

Projeto desenvolvido como **teste técnico para uma vaga de desenvolvimento**.

O objetivo do desafio é avaliar conhecimentos em **C# .NET 8**, **Entity Framework Core**,
**Windows Forms** e **padrões de arquitetura**, por meio da construção de um sistema de
cadastro e gerenciamento de produtos.

## Tecnologias

- C# / .NET 8 (`net8.0-windows`)
- Windows Forms
- Entity Framework Core
- Padrão MVVM

## Estrutura atual

Este commit representa o **ponto de partida do projeto**: a solução Windows Forms criada
e configurada para .NET 8, pronta para receber a implementação das funcionalidades.

```
ProductChallenge/
├── ProductChallenge.sln
├── ProductChallenge.csproj
├── Program.cs
└── Form1.cs
```

## Como executar

Pré-requisitos: [.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0) e Windows.

```bash
dotnet build
dotnet run
```

Ou abra o arquivo `ProductChallenge.sln` no Visual Studio 2022 e execute com `F5`.
